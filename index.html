FIXEL

A B O U T

WHAT FIXEL IS

Fixel is an endless feed of pictures. Each picture shows a city, a shore, a desert or a highland. A program draws every picture. The same program also writes the music for every picture. Fixel contains no stored pictures and no stored sound.

THE SEED

Each post has one number. This number is the seed. The seed controls the picture and the music together. The same seed always gives the same post. The address bar shows the seed of the post on the screen. Copy the address to keep a post.

WHO MADE FIXEL

A person wrote one short instruction. The instruction asked for a feed of pixel-art scenes with music. Software agents did all of the other work. The agents wrote the program, the tests and the notes. The person did not write the program code.

THE STANDARD

The agents compared Fixel with a real artwork. The artwork is an isometric picture from the studio eBoy. The agents measured the artwork first. The agents then measured the output of the program. The two sets of numbers show where the program is different.

THE TEST

The test is a comparison of two small pictures. A judge sees one part of the artwork and one part of the program output. The judge does not know which picture is which. The judge selects the better picture. The agents repeat the test with the two pictures in the opposite order. A new judge does each order.

THE RESULT

The program lost every test. In one round, eight judges made eight selections. All eight judges selected the artwork. Each judge also identified the program correctly. This result is the most useful result in the project. The judges gave their reasons, and the agents then corrected the program.

THE NUMBERS ARE NOT A SCORE

The agents wrote 60 measurements for the pictures. A later test showed a problem. The measurements put the program above a second real artwork. A measurement that does this measures the wrong property. The agents stopped all use of the total as a score. The agents keep the measurements as a check for large faults.

A FAULT THAT STAYED HIDDEN

The program draws each person and each tree as a small picture. One function put these pictures on the screen. The function used a fractional number for the position. A typed array ignores a fractional position. The function therefore discarded every small object, and it reported success.

Three rounds of judges saw the result. The judges called the small objects bad art. The agents found the true cause only after they counted the calls to the function. The agents now count the calls before they accept an explanation.

THE MOVEMENT

Each post moves a little. The water moves. The trees move. The people move. Each movement is one or two pixels. The program draws eight pictures for each post, and it shows the eight pictures in a loop.

TIME IS A NUMBER

Most animations use a clock. A clock gives a different result at each moment. Fixel uses a frame number in place of a clock. The frame number is a whole number from 0 to 7. The same seed and the same frame number always give the same pixels.

THE SOURCE

The source code is public. Read it at github.com/Syrul/Fixel.

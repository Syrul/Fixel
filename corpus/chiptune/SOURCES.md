# CC0 chiptune corpus — sources and licence verification

38 tracks, all from OpenGameArt, all released under **CC0 1.0 Universal** (public domain
dedication, no attribution required). Every submission page in the table below was fetched directly
and its licence block checked for the string `publicdomain/zero/1.0`; all 24 distinct
pages returned it. Nothing in this corpus is included on the strength of a search-result label.

Attribution is not required by CC0, but authors are recorded anyway.

## Sources that were tried and rejected

| Source | Outcome |
|---|---|
| **freepd.com** | **Dead — no tracks taken.** The site now serves only a "Site Closed" notice; `/electronic.php`, `/upbeat.php` and `/music/*.mp3` all return HTTP 404. Nothing was downloadable, so nothing was used. |
| **archive.org** | Search backend returned `[BACKEND_ERROR] Invalid or no response from Elasticsearch`. No licence could be confirmed, so nothing was taken. |
| **ozzed.net** | Rejected: the site requires credit and its footer links CC-BY-SA 3.0. Not CC0. |
| **incompetech / Kevin MacLeod** | Rejected: CC-BY 3.0, attribution required. Not public domain. |
| **OpenGameArt `free-action-chiptune-music-pack`** | Rejected: CC-BY 4.0 only. |
| **Wikimedia Commons chiptune set** | Verified CC0/PD candidates existed, but were not needed once 38 CC0 tracks were confirmed on OpenGameArt. Some Drozerix items use the CC Public Domain Mark rather than a CC0 dedication; none were used. |

No track was kept whose licence could not be confirmed, and none was deleted after the fact — the
verification pass ran before the download, so unverified candidates were never fetched.

## Canonical form

Originals are kept in `corpus/chiptune/orig/` exactly as downloaded. Every track is converted to a
single canonical form for measurement, with no normalisation and no filtering:

```
ffmpeg -i <orig> -ar 44100 -ac 1 -c:a pcm_s16le corpus/chiptune/wav/<name>.wav
```

44100 Hz, mono, 16-bit PCM. The only transformations are resampling and channel downmix; no gain,
no EQ, no dynamics. `corpus/chiptune/manifest.tsv` holds the same table in machine-readable form.
